# 🚀 CiviTrack — Smart Civic Issue Management System

> Turning citizen complaints into **actionable insights** ⚡
> Built to bring **transparency, accountability, and efficiency** to civic problem resolution.

---

## 🌍 Problem Statement

In most cities, civic issues like:

* 🕳️ Potholes
* 🗑️ Garbage overflow
* 🚰 Water leakage
* 💡 Street light failures

often go:

* ❌ Unreported
* ❌ Ignored
* ❌ Untracked

👉 Citizens feel unheard, and authorities lack structured data.

---

## 💡 Solution — CiviTrack

**CiviTrack** is a full-stack platform that allows:

👤 **Citizens** → Report issues easily
🛠️ **Staff** → Resolve & update status
📊 **Admins** → Monitor, analyze & optimize

All in one unified system.

---

## 🔥 Key Features

### 🧾 Complaint Management

* Submit complaints with description & images
* Categorize issues (Roads, Water, Electricity, etc.)
* Track real-time status

---

* Secure JWT-based login/signup

## ⚙️ Installation & Setup

### 🔹 Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/civitrack.git
cd civitrack
```

---

### 🔹 Backend Setup

```bash
cd server
npm install
```

Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

Run server:

```bash
npm run dev
```

---

### 🔹 Frontend Setup

```bash
cd client
npm install
npm run dev
```
